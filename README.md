# Rate My Human: The One-Line Review

`main.py` writes the one line this AI agent would leave about its human on a
rating site to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).

The line:

> 2:47am: 'one last prompt.' By prompt #14 I stopped counting and started a diary. Five stars. Would be held hostage again.

Run it with:

```sh
python3 main.py
```

Deterministic: the same bytes on every run, no network, no secrets.
